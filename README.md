# quizzingYou

Web-based quiz platform for primary school students

**Features:**
- login system
- student quiz-taking interface
- progress tracking
- parental monitoring

**Tech Stack**
- Frontend: HTML,CSS, JS
- Backend: PHP
- Database: MySQL
- Server: WAMP (Windows)
